# RAG Chatbot
A Retrieval-Augmented Generation (RAG) Chatbot system consisting of a NestJS backend and a React/Vite frontend.

## Project Structure

- `document-rag/`: NestJS backend API service for RAG document processing and chatbot operations.
- `document-rag-ui/`: React + Vite frontend application for interacting with the RAG Chatbot.

## Getting Started

### 1. Backend (`document-rag`)

```bash
cd document-rag
npm install
npm run start:dev
```

### 2. Frontend (`document-rag-ui`)

```bash
cd document-rag-ui
npm install
npm run dev
```
